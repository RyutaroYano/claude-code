# claude-code

Claude Code を使っていろいろな作業をするための、作業用リポジトリです。
調査、分析、文章づくりなど、テーマごとにディレクトリを分けて、作業の成果をためていきます。

## ディレクトリ構成のルール

作業ごとにディレクトリを1つ作り、中を次のように分けます。

```
<作業名>/
├── scripts/   # 作業に使ったプログラム（Python など）
└── output/    # 出力したファイル（テキスト、表、スプレッドシートなど）
```

このファイル（ルートの README.md）には、作業の一覧だけを書きます。作業の結果は各ディレクトリの `output/` に置きます。
