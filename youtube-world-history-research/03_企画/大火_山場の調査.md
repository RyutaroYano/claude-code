# 大火（江戸とロンドン）：山場の調査

- 作成：2026-10-23
- 調べた問い：
  1. ロンドンは、なぜ大火の前は木造だったのか
  2. ロンドンは、なぜ大火のあと石や煉瓦にしたのか
  3. 江戸は、燃えたあと、なぜ木のままにしたのか（地震に強い、以外の理由）
- 確からしさの付け方は設計書 第11章のとおり。今回もすべて検索結果の引用・要旨で確かめたもので、出典の本文は開けていない。

---

## 結論：台本として成り立つ

山場の答えは、思っていたより強いものが見つかった。

> **大火のあと、江戸は「燃えない屋根」を禁じた。**

明暦の大火の直後、幕府は町の家に瓦屋根を使うことを禁じた。大火のとき、落ちてきた瓦でけがをしたり、下敷きになったりした人が多かったため、とされる。燃えない材料に変えたロンドンと、逆の手を打っている。これが④伏せの答えになり、②裏切りにも使える。

そのうえで、江戸の答えは「燃えない町」ではなく、次の4つを組み合わせた「燃えても止め、すぐ建て直す町」だった、とまとめられる。

1. 空き地（火除地）と広い道で、燃え広がりを止める。
2. 火消しが家を壊して、燃え広がりを止める（壊しやすい家が、かえって役に立った面がある）。
3. 財産は土蔵に入れて守る。家は燃えても、建て直す材木を前もって材木屋に預けておく商家もあった。
4. 燃えない家（瓦屋根・土蔵造り）は、60年あまり後に許し、勧めた。ただし強制はせず、幕府にお金がなくなると進まなかった。

ロンドンの側にも、意外な事実がある。

- ロンドンも、大火の80年以上前から、「煉瓦か石で建てよ」という命令を何度も出していた。ただし、守られていなかった。
- 命令の理由は、火事だけではなかった。国じゅうで木材が足りなくなっていた。
- 大火のあとの1667年、法律で、木造の家を建てることを禁じた。命令が初めて本気で守られた。
- 大火のあと、ロンドンでは火災保険が生まれた。保険会社は、自分で消防の人を雇った。

さらに「今」に、こうつなげられる。

- 明治になって、日本は一度ロンドンの答えを試している。1872年に銀座が燃えたあと、銀座を煉瓦の町にした（銀座煉瓦街）。ところが、家賃が高く、湿気で評判が悪く、空き家が増えた。東京全体を煉瓦にする計画は、お金がなくて立ち消えた。

## 1. ロンドンは、なぜ大火の前は木造だったのか

| 事実 | 確からしさ | 出典 |
|---|---|---|
| 大火の前のロンドンの家は、ほとんどが木の骨組みに漆喰を塗った数階建てで、上の階が通りに張り出していた | ○ | Gresham College の講演「London's Great Fire and its Aftermath」／London Museum の記事 |
| 1580年から、政府は何度も、建物を煉瓦にするよう決まりを出していた。ただし新しい家だけが対象で、守られたのは時々だった | ○ | Gresham College／Promat の消防規制の歴史 |
| 1605年、ジェームズ1世は、ロンドンの新しい家を煉瓦か石で建てるよう命じた。国じゅうの木材が尽きかけていることを理由に挙げていた。1607年にも同じ命令を出した | ○ | 1605年の布告の本文の目録（オックスフォード大学 Text Archive, STC 8370）／UK の木造建築史の解説 |
| 大火の前から、ロンドンには煉瓦の建物もたくさんあった | △ | London Museum の「大火の3つの誤解」（本文未確認） |

**台本で言えること：** ロンドンも、昔から「木はやめよう」と言い続けていた。それでも木で建て続けていた。燃えるまでは変わらなかった。

**まだ確かめていないこと：** 木造が続いた理由（木の方が安い、早く建つ、大工の技術）を、経済史の研究で確かめたもの。今は「慣れていて、すぐ手に入る材料だった」までしか言えない。

## 2. ロンドンは、なぜ大火のあと石や煉瓦にしたのか

| 事実 | 確からしさ | 出典 |
|---|---|---|
| 1666年の大火で、約1万3200軒の家と、80以上の教会、セント・ポール大聖堂が焼けた | ○ | 複数の百科事典・解説（教会の数は87と89で出典ごとに違う → 言わない） |
| 記録に残る死者は6人。ただし、本当の死者はもっと多かったという研究者の説がある | ○ | Londonist／Neil Hanson 2001 の紹介 |
| 1667年の再建法で、新しい建物は煉瓦か石で建てることになり、木の骨組みの家や、通りへの張り出しが禁じられた。通りの幅と家の大きさも決められた | ○ | 英国議会のサイト／legislation.gov.uk の法令本文の目録／Designing Buildings |
| 再建の費用は、ロンドンに入る石炭にかけた税でまかなった | ○ | 英国議会のサイトの紹介 |
| 1673年の終わりまでに、約8000軒が建て直された | △ | 一般向けの解説1つ |
| 1680年ごろ、ニコラス・バーボンが火災保険の会社を作り、自分で消防の人を雇った。1690年には、ロンドンの家の10軒に1軒が保険に入っていた | ○（年は1667年とする出典もある） | London Museum のブログ（検索結果の引用）／ロンドン消防局の博物館のページ |

**台本で言えること：** 大火で、これまで守られなかった「煉瓦か石で」が、初めて法律で強制された。費用は石炭の税。さらに、燃えたら補償する「保険」という答えも生まれた。

## 3. 江戸は、燃えたあと、なぜ木のままにしたのか

| 事実 | 確からしさ | 出典 |
|---|---|---|
| 明暦の大火は1657年。死者は6万8000余人とされる（10万人を超えたとする資料もある） | ○（数は言い方を弱める） | 内閣府「1657 明暦の江戸大火」報告書 |
| 大火の直後、幕府は瓦葺きを禁じた。国持大名でも禁止、倉庫だけは許した（『徳川実紀』の記述として紹介） | ○ | 防災情報機構の周年災害の解説／Wikipedia「江戸の火事」 |
| 瓦葺きを禁じた理由は、大火で落ちてきた瓦でけがをした人、下敷きになった人が多かったため、とされる。建築費がかさむことを挙げる資料もある | ○（理由の重みは資料ごとに違う） | 同上（2つ以上の資料で一致） |
| 復興では、大名屋敷や寺を移し、火除地や広小路を設けた | ○ | 内閣府の報告書／東京都の資料 |
| ただし「明暦の大火のあとの都市改造が新しい江戸を作った」という通説には、見直しを求める研究がある | ○ | 岩本馨『明暦の大火 「都市改造」という神話』吉川弘文館（京都工芸繊維大学の紹介） |
| 当時の消火は、家を壊して燃え広がりを止める「破壊消防」が中心だった | ○ | 内閣府の報告書／東京消防庁 |
| 1718年に町火消ができた。1720年、大岡忠相が、それまで禁じられていた瓦葺き・塗屋・土蔵造りを許し、勧めた。強制はしなかった | ○ | 東京消防庁の資料／防災情報機構 |
| 勧めるために、税の免除や、10年払いの貸付けも行った | △ | 防災情報機構の解説1つ |
| 瓦葺き以外を禁じる決まりができたのは1792年 | △ | 東京消防庁の資料1つ |
| 吉宗が亡くなると、幕府にお金がなくなり、燃えない家を進める手は打たれなくなった | △ | Wikipedia「江戸の火事」（元の文献をたどる） |
| 江戸の防火の柱は、火除地、燃えない建物、消防の組織の3つで、燃えない建物の決まりは享保の後に緩んでいった | ○ | 森下雄治 立命館大学 博士論文（英文要旨と目次）https://ritsumei.repo.nii.ac.jp/record/10632/files/k_961.pdf |
| 江戸の家は安く建てられていて、それが大火を大きくした面と、壊しやすく建て直しやすいことで燃え広がりを防いだ面の両方があった | △ | Wikipedia「江戸の火事」 |
| 裕福な商家は、家1軒分の材木を材木屋に預けておき、焼けたらすぐ建て直して商売を始めた | △ | Wikipedia「江戸の火事」（元の文献をたどる） |
| 大火のあと、河村瑞賢は木曽の材木を買い占めて大きな利益を得た | ○ | 信州大学の論文／文春オンライン |
| 江戸では、大火だけで約90件、小さな火事を含めると約2000件の火事があったとされる（大火を49回とする資料もある） | △（数は言わない） | 文藝春秋／和楽 |
| 1855年の安政江戸地震では、土蔵の壁が落ちた記録がある | ○ | 歴史地震の論文（中村操ほか） |

**台本で言えること：**
- 燃えない屋根を、大火のあとにあえて禁じた（落ちる瓦が人を殺した）。
- 江戸は「燃えない家」より、「燃え広がりを止める」「財産を土蔵で守る」「すぐ建て直す」に力を入れた。
- 燃えない家は、60年あまり後に許し、勧めた。ただし強制はしなかった。
- 「日本の家が木造なのは地震に強いから」だけでは説明しきれない。燃えない土蔵も、地震では壁が落ちた。

**考えられる理由として言えること（研究者が言い切ってはいない）：** 江戸では、町じゅうを燃えない家にする費用を、幕府も町人も負えなかった。燃えたら建て直す方が、町の仕組み（材木の流れ、職人、火消し）に合っていた。

**まだ確かめていないこと：**
- 瓦禁止の『徳川実紀』の原文と日付（1657年の何月か）。
- 「燃えたら建て直す方が安かった」ことを、数字で示した研究（材木の値段、職人の賃金）。
- 岩本馨の本で、どの通説が見直されているか（火除地・広小路の話を言い過ぎないため）。

## 4. 今：日本は一度、ロンドンの答えを試した

| 事実 | 確からしさ | 出典 |
|---|---|---|
| 1872年の銀座の大火のあと、政府は銀座を煉瓦の町にした（銀座煉瓦街） | ○ | 東京都公文書館／日本損害保険協会の資料 |
| 煉瓦街は、家賃が高いことを主な理由に空き家が増えた。雨漏りや湿気の悪い評判もあった | ○ | 日本損害保険協会の資料／東京都建設局の広報誌 |

## 5. 企画の形（たたき台）

| 部品 | 中身 |
|---|---|
| ①当たり前 | 日本の家は木造（地震に強いから）。ヨーロッパの町は石と煉瓦 |
| ②裏切り | ロンドンも大火までは木造の町で、「煉瓦にせよ」という命令を80年以上無視していた。江戸は大火のあと、燃えない瓦屋根を禁じた |
| ③証拠 | 燃える前のロンドンの木造の町並み（ホラーの「ロンドン鳥瞰図」など、使用条件は未確認）／明暦の大火を描いた『むさしあぶみ』の挿絵（使用条件は未確認） |
| ④伏せ | なぜ江戸は燃えない町にしなかったのか |
| ⑤持ち帰る見方 | 「燃えない家を作る」と「燃えても止め、すぐ建て直す」。同じ大火への2つの答え。日本の木の家は、地震だけでなく火事とも付き合ってきた形 |

### 章立て案

| ブロック | 見出し | 中身 |
|---|---|---|
| 01 つかみ | 同じ大火なのに？ | 1657年の江戸、1666年のロンドン。どちらも木の町が燃えた。ロンドンは石の町に、江戸は木の町のまま |
| 02 前提 | 燃える前の2つの町 | 木造のロンドン（張り出した家、狭い道）と、江戸の町家。2つの大火の様子 |
| 03 理由① | ロンドンは「80年言い続けたこと」をやっと実行した | 1580年からの煉瓦の命令、木材不足、1667年の再建法、石炭の税 |
| 04 理由② | 江戸は燃えない屋根を禁じた | 瓦の落下、破壊消防、火除地、土蔵、材木を預ける商家 |
| 05 理由③・まとめ | 燃えない家は、許しても広がらなかった | 1720年の奨励と、強制しなかったこと、幕府のお金。地震では土蔵の壁も落ちた（理由ではなかったもの：地震だけでは説明できない） |
| 06 答えと今・締め | 日本は一度、ロンドンの答えを試した | 銀座煉瓦街の失敗、関東大震災。保険の国と、火消しの国。持ち帰る見方 |

- タイトル案：ロンドンは大火のあと石の町に。同じように燃えた江戸が木の町のままだった意外な理由
- サムネの問い：同じ大火なのに？
- 注意：何万人もの人が亡くなった災害。燃える場面は遠景と炎だけにし、人が焼ける場面は作らない。死者の数を「どちらが多いか」で比べない。
