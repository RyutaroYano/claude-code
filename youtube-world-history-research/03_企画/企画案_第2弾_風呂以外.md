## 3. 1本ずつの中身

### 企画1　大火：ロンドンは石の町に、江戸は木の町のまま

| 部品 | 中身 |
|---|---|
| ①当たり前 | 日本の家は木造。ヨーロッパの町は石や煉瓦 |
| ②裏切り | ロンドンも、大火の前は木造の町だった。江戸の大火のわずか9年後に、同じように燃えた |
| ③証拠 | 燃える前のロンドンの木造の町並みの絵／明暦の大火の絵巻（同じ構図で並べる） |
| ④伏せ | なぜ江戸は石の町にしなかったのか |
| ⑤持ち帰る見方 | 「燃えない町」と「燃えても止められる町」。同じ大火への2つの答え（台本の段階で事実から詰める） |

- タイトル案：ロンドンは大火のあと石の町に。同じように燃えた江戸が木の町のままだった理由
- サムネの問い：同じ大火なのに？
- チェック：1○ 2○（日本の家はなぜ木造か） 3○ 4○ 5○ 6○ 7◎（燃える町並みを同じ構図で）
- 史料：明暦の大火の絵（『むさしあぶみ』など、使用条件は未確認）／ロンドン大火の絵（ロンドン博物館などに複数、未確認）
- 確かめたこと：
  - 明暦の大火は1657年。死者は6万8千余人（内閣府の資料）、10万人超とする資料もある → 数字は言わない（○）
  - 復興で、火除地・広小路を設けた（内閣府、東京都の資料）（○）
  - ロンドンは1667年の再建法で、新しい建物を煉瓦か石に限った（英国議会の資料、法令の本文 legislation.gov.uk）（○）
  - 1720年、大岡忠相が瓦屋根・塗屋・土蔵造りを奨励した。強制ではなかった。瓦葺き以外を禁じたのは1792年（東京消防庁の資料）（△：出典が1つ）
- まだ確かめていないこと：江戸がなぜ石や煉瓦にしなかったか（地震、費用、材木の流通）の研究。ここが本編の山場になる。

### 企画2　印刷：活字は日本にも来ていた

| 部品 | 中身 |
|---|---|
| ①当たり前 | 活版印刷は世界三大発明。江戸の本や浮世絵は木版 |
| ②裏切り | 1590年代、日本にも活字が来て、天皇や家康が活字で本を作っていた |
| ③証拠 | グーテンベルク聖書のページ／キリシタン版または慶長勅版のページ |
| ④伏せ | なぜ日本は木版に戻ったのか |
| ⑤持ち帰る見方 | 文字の数と、刷る部数が、道具を選ぶ（台本の段階で詰める） |

- タイトル案：活版印刷は日本にも来ていた。なのに江戸の本が木版に戻った意外な理由
- サムネの問い：活字、来てたのに？
- チェック：1○ 2○（学校で習った三大発明） 3○ 4○ 5○ 6◎ 7○（工房の場面を並べる）
- 史料：キリシタン版（天理図書館、長崎など）、駿河版（凸版印刷の印刷博物館に銅活字）、グーテンベルク聖書（パブリックドメインの画像が多い）。使用条件は未確認
- 確かめたこと：
  - イエズス会が印刷機を持ち込み、1591年に加津佐で最初のキリシタン版。1614年の禁教で中止（長崎市、日本印刷産業連合会）（○）
  - 文禄の役のころ朝鮮から活字の技術が来て、1593年に後陽成天皇の勅版（コトバンク：日本大百科全書）（○）
  - 古活字版は慶長〜寛永前半の約35年に300点以上。組み直しの手間から、需要が増えると整版（木版）に移った（世界大百科事典、近畿大学の論文）（○）
- まだ確かめていないこと：木版に戻った理由の専門書（川瀬一馬『古活字版の研究』）での確認。ヨーロッパで活字が残った理由（アルファベットの字数）は一般論なので、出典を探す。

### 企画3　肉食：肉を断つ決まりと、その抜け道

| 部品 | 中身 |
|---|---|
| ①当たり前 | 昔の日本人は肉を食べなかった |
| ②裏切り | 日本では猪を「山鯨」と呼んで食べていた。ヨーロッパでもビーバーの尾を「魚」として食べていた |
| ③証拠 | 「山くじら」の看板が描かれた浮世絵（広重『名所江戸百景 びくにはし雪中』）／ビーバーの絵のある中世の動物誌 |
| ④伏せ | なぜ、決まりを守りながら肉を食べられたのか |
| ⑤持ち帰る見方 | 決まりの「言い換え」で暮らしを守るのは、どこも同じ。違うのは、何を禁じたか（日=動物の種類、欧=曜日） |

- タイトル案：肉を食べてはいけない日に、ヨーロッパの人と江戸の人が食べていたもの
- サムネの問い：これは魚です
- チェック：1○ 2○ 3○ 4○ 5○（違いより「同じ」が強い。切り口に合うかは要相談） 6○ 7○（店先の場面）
- 確かめたこと：
  - 675年（676年とする資料も）、天武天皇が牛・馬・犬・鶏・猿の肉食を禁じた（日本書紀、複数の解説）（○。年は言い方を弱める）
  - 江戸後期にももんじ屋があり、『江戸繁昌記』（1832）に山鯨の店が描かれる（○）
  - 1872年に明治天皇が肉を食べたことが公表された（○）
  - ビーバーの尾：12世紀にギラルドゥス（ジェラルド・オブ・ウェールズ）が、断食期に聖職者が尾を食べていたと記録。18世紀にはパリの神学部が、尾は魚と同じとして断食日に許した（Scientific American、Salon の紹介）（○。一次史料は未確認）
- まだ確かめていないこと：「兎を一羽と数えるのは肉食の言い逃れ」は俗説の可能性が高い → 使わない。フジツボガンの話は出典が弱い → 使わない。

### 企画4　時計：同じ機械時計を、日本は改造した

- ①1時間はいつも60分 ②江戸の1時間は、夏と冬で長さが違った ③西洋の機械時計／和時計（国立科学博物館に多数） ④なぜ時計の方を変えたのか ⑤道具は、暮らしの時間に合わせて作り変えられる
- タイトル案：同じ機械時計なのに。江戸の時計だけ、季節で針の進み方が変わった理由
- 確かめたこと：不定時法は昼と夜をそれぞれ6等分。和時計は一挺天符・二挺天符・割駒式文字盤で対応した。1872年の改暦で定時法に変わった（国立科学博物館の論文と学習資料、名古屋市科学館）（○）
- 弱いところ：ヨーロッパも昔は不定時法（教会の時課）だった。機械時計が来てヨーロッパは「時計に暮らしを合わせ」、日本は「暮らしに時計を合わせた」と言えれば分かれ道になる。ここは未確認

### 企画5　暖房：部屋を暖めるか、人を暖めるか

- ①日本の家は冬寒い（ターゲットの体験に一番近い） ②昔から部屋を暖める考えがなかった ③暖炉のある部屋／囲炉裏端（同じ構図） ④なぜ部屋を暖めなかったのか ⑤「夏をむねとすべし」
- 確かめたこと：日本の伝統的な暖房は、部屋ではなく人や近くの空間を暖めた（北海道大学の論文、熊本県立大学の講義資料）（○）。『徒然草』の「家の作りやうは夏をむねとすべし」（○）
- 弱いところ：ヨーロッパの暖炉・煙突がいつ庶民に広がったかが未確認。

### 企画6　鉄砲：日本は鉄砲を捨てたのか

- ①戦国の日本は鉄砲大国だった ②江戸で鉄砲は「捨てられた」と言われるが、研究では誤り ③火縄銃（日本）と同時代のマスケット（欧） ④使われなくなった本当の理由 ⑤武器は、戦争がなくなると改良されなくなる
- 確かめたこと：ペリン『鉄砲を捨てた日本人』（1979）に対し、ロージやトットマンが「捨てたのではなく、泰平で必要なくなった」と反論している（○）
- 注意：需要は大きいが、「世界最大の銃保有国」など日本スゴイの言い方が多い題材。比べ方を「同じ問題（戦がなくなった後、武器をどうする）」に置けるかが鍵。

## 4. おすすめの3本

1. **大火（江戸とロンドン）**：9年差で同じ問題が起きた、一番きれいな「同じ問題に、違う答え」。再現VTRで燃える町を同じ構図で並べられる。片方だけの動画は13〜14万回見られていて、比べた動画はまだない。今の「日本の家はなぜ木造か」にもつながる。
2. **印刷（活字と木版）**：同じ活字が日本にも来ていたという、②裏切りが強い分かれ道。学校で習った「三大発明」が①になる。比べた動画がない。
3. **肉食（抜け道）**：需要が一番大きい（日本側だけで400万回）。ただし、中身は「違う答え」より「同じ抜け道」になるので、切り口に合うかは相談したい。
