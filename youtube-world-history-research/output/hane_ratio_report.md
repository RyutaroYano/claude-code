# 世界史ジャンル「はねた動画」率リサーチ

- 取得日：2026-10-08（vidIQ のデータ）
- 定義：**はねた動画 ＝ 再生数がそのチャンネルの現在の登録者数を上回った動画**
- はね率 ＝ はねた本数 ÷ 判定した本数（公開から7日未満の動画は判定から除外）

---

## 結論

1. **3ヶ月以内に開設して登録1,000人を超えた歴史系チャンネルは、少なくとも8つ見つかりました。** はね率の上位は「歴史発見録（98%）」「世界史の奇録（90%）」「歴史と神話の舞台裏（89%）」「戦場映画ノート（80%）」「夜の退屈な歴史（77%）」です。
2. ただし、**はね率は登録者が少ないほど高く出る指標です。** 登録1,700人のチャンネルなら1,700回再生で「はねた」になりますが、登録47万人なら47万回必要です。そのため、新しいチャンネルが上位に来るのは半分は構造上の理由です。
3. その前提で見ると、**本当に強いのは「世界見聞録」です。** 登録47万人なのに、直近50本の70%が47万回を超えています。世界史ジャンルの「勝ちテーマ」の見本になります。
4. ビギナーが参考にするなら、**「おもしろ世界史ラボ」と「消えたものたちの博物館」が一番役に立ちます。** どちらも最初の企画が全く伸びず（1本あたり約100〜1,000回）、途中で企画の型を変えてから一気にはねました。最初から当たっていたのではなく、「方向転換して当てた」記録が残っているからです。

**表の読み方**
- 「再生数中央値÷登録者」が1を超えていれば、半分以上の動画が登録者数より多く再生されているという意味です。登録者の規模の違いを少しならした比較に使えます。
- 「最大再生÷登録者」は一番はねた1本の倍率です。100を超えるチャンネルは、1本の大当たりで登録者を一気に集めた型です。

## 3ヶ月以内に開設されたチャンネル（優先調査分）

### 歴史発見録（ショート｜開設8/22｜はね率98%）
- 1本約1分。徳川家の正室・姫、皇族の女性、世界史上の女性（ココ・シャネル、エリーザベト、マリー・テレーズなど）の人物史を扱っています。
- 1日1〜2本投稿。「徳川慶喜の孫として生まれ」（11.8万回）、「美しすぎて追われた満竜」（11.7万回）、「最後の将軍・徳川慶喜の孫娘」（10.3万回）。
- **型**：「〇〇の正室」「〇〇の孫娘」という同じ形のシリーズを大量に出しています。ショートは再生が登録者数の影響を受けにくいので、はね率がほぼ100%になります。

### 世界史の奇録（ショート｜開設7/26｜はね率90%）
- 1本約1分。「信じられないけど史実」の冷戦・軍事・奇妙な事件を毎日1本出しています。
- 「北朝鮮に奪われ、今も返ってこないアメリカ軍艦」（31.6万回）、「日本の島から約130km、今も海底に眠る水爆」（27.6万回）、「漁師の網に捕まった北朝鮮の潜水艇」（26.8万回）。
- **型**：タイトル1行に「意外な結末」を入れています。日本と関係のある話題が特に強い傾向です。

### 歴史と神話の舞台裏（長尺｜開設6/24｜はね率89%）
- 約25分。古事記・日本書紀の神々を「政治的な思惑」から読み解く内容で、週1〜2本。AI音声とAI画像を使っていると明記しています。
- 「ツクヨミ」（24.5万回）、「宗像三女神」（16.7万回）。
- 世界史ではなく日本神話ですが、**長尺でも新しいチャンネルがここまで安定してはねる**例です。

### 戦場映画ノート（ショート｜開設7/8｜はね率80%）
- 第二次世界大戦の戦争映画を約2分で紹介しています。97.9万回、88.1万回、86.6万回の動画があります。
- **注意**：映画本編の映像を使う形式なので、著作権の申し立てや収益化停止のリスクが高いです。参考にするのは「数字の出方」だけにとどめた方がいいです。

### 夜の退屈な歴史（長尺｜開設7/4｜はね率77%）
- 1時間〜1時間40分の「寝落ち用」歴史ラジオで、週1本。
- 「江戸の町と夜の暮らし」（10.3万回）、「江戸の宿場町と旅人の一夜」（8.1万回）、「古代ローマの浴場とパン屋の一日」（4.9万回）。
- **型**：事件や人物ではなく「ある時代の人々の一日」を淡々と語る形式です。15本で登録1,640人。投稿本数が少なくても成り立つのが特徴です。

### 軍事ファイル（長尺｜開設8/4｜はね率50%）
- 約30分の戦史解説を、ほぼ毎日1本。中央値は約1,100回で、登録者数とほぼ同じです。
- 当たりは「マリアナ沖海戦」（3.8万回）の1本だけ。**投稿数で押し切る型**で、ビギナーが真似すると息切れしやすいです。

### 消えたものたちの博物館（長尺｜開設7/29｜はね率38%）
- **方向転換の記録として一番参考になります。**
  - 最初の約10本は「マヤ文明はなぜ滅んだ？」「インダス文明」「ミノア文明」など5分のずんだもん解説で、**再生数は63〜358回と全滅**でした。
  - 8/9から「消えた家電メーカー5社の『その後』」という形式に変えると、7.5万回、23.1万回、9.6万回、10.2万回と連続してはねました。
- 教訓：**「古代文明×短い尺」は伸びず、「身近なモノ×その後×5つ並べる」が伸びた**ということです。

### 人類のナゾ（長尺｜開設7/11｜はね率32%）
- 古代人類・縄文人・進化の謎をアニメ調で解説しています。
- 「古代人類は、終わらない雨をどうやって生き延びたのか｜縄文人が雨と暮らした一万年」（19.2万回）が1本だけ大当たりし、ほかは500〜3,000回です。
- **型**：「現代の自分の悩み（眠い、雨の日にだるい、腰痛）」を「人類の進化」で説明する切り口です。矢野さんの専門（人類進化論）に一番近いチャンネルです。

### 眠れる知識室 / ノア（参考）
- 眠れる知識室：「なぜ予定が一つあるだけで、休日は一日つぶれた気がするのか」（93.4万回）で一気に伸びましたが、中身は心理学で、歴史ではありません。
- ノア：登録8.5万人まで伸びた新しいチャンネルですが、主力はショート（166本）です。今回取得できた長尺14本のはね率は9%でした。

## ビギナーにとっての読み取り

1. **最初の数本が伸びないのは普通です。** おもしろ世界史ラボの最初の3本（ハンニバル、帝国の忘却など）は約1,000回でした。4本目で「なぜイベリア半島は2つに分かれたのか」（22.1万回）が当たり、その後「なぜ〇〇と〇〇は別の国なのか」という型を続けて伸びています。
2. **当たる型には共通点があります。** 「なぜ〜なのか？」という問いと、地図・国・身近なモノを入り口にした比較です。人物伝や古代文明そのものを正面から扱うと、新しいチャンネルでは伸びにくい傾向でした。
3. **ショートは、はね率を上げやすい一方で、登録者が増えにくい可能性があります。** 歴史発見録は直近50本のうち35本が1万回を超えていますが、登録者は1,780人です。
4. **新しく伸びているチャンネルの多くは、AI音声・AI画像・顔出しなしです。** 制作量で勝負できる一方、YouTubeは量産型・繰り返し型のコンテンツを収益化の対象外にする方針を出しています。同じ型を大量に出すやり方には、その意味でのリスクがあります。

## 調査の限界

- vidIQ の API では、1チャンネルにつき形式ごと（長尺／ショート）に新しい順で最大50本までしか取れません。大手3チャンネルは直近50本だけで判定しています。
- 登録者数は「現在の値」です。公開した時点の登録者数ではないため、初期の動画ほど判定が厳しくなります。
- 長尺とショートは別々に集計しています（ノアは長尺だけ、ショート主体のチャンネルはショートだけ）。
- YouTube に直接アクセスできない環境だったため、すべて vidIQ 経由のデータです。vidIQ のクレジットはほぼ使い切りました（残り10）。
- データは `scripts/data.py`、集計は `scripts/analyze.py` です。`python3 scripts/analyze.py` を実行すると、表が `output/hane_ratio_table.md` に再生成されます。

条件：顔出しなし・合成音声やAIで作れる形式／世界史／長尺。おもしろ世界史ラボと世界史裏探訪に続く「3つ目のモデル」の候補を探しました。

**読み取り**
- 戦いのヒストリアと教養としての世界史chは、全体のはね率は高いものの、そのほとんどは2023〜2024年の動画によるものです。**今年の動画だけで見ると、はねなくなっています。**
- **今もはね続けているのは「追伸、戦場から失礼します。」だけ**です。登録者の規模が小さいことを割り引いても、14本すべてが登録者の3倍以上再生されています（中央値は8.4倍）。
- 五回目は正直は、題材が世界史裏探訪とほぼ同じ（中世ヨーロッパの生活史）です。ただ、登録者に対して再生が安定しすぎていて、「はねる」タイプではありません。

**はねた動画の例（追伸、戦場から失礼します。）**
- イルマ・グレーゼ｜22歳で処刑された悪魔。ナチスが最も恐れた女の残酷すぎる最期（57.4万回）
- スターリンの最期！1000万人を殺した男の残酷すぎる7日間（51.0万回）
- アドルフ・アイヒマン｜500万人を殺した男。ナチスが最も恐れた男の残酷すぎる最期（24.5万回）

※顔出しをしていないことは、タイトルとチャンネル説明から判断しました。動画そのものは確認できていません。ゆっくり解説の2チャンネル（戦いのヒストリア、五回目は正直）は、名前のとおり合成音声です。
