## 1. 決まっていること

| 項目 | 内容 |
|---|---|
| チャンネル | そこここ世界史 |
| 同じ問題 | 汚れと病気に、町でどう向き合うか |
| 世界の答え | ヨーロッパの都市には公衆浴場があったが、15世紀末〜16世紀に減っていった |
| 日本の答え | 日本にも町の風呂屋があり、取り締まりを受けながらも残った |
| タイトル | 同じ「町の風呂屋」があったのに。ヨーロッパだけ浴場が消えた意外な理由 |
| サムネ | 上の帯：黒地に黄色で「ヨーロッパ」「日本」。真ん中に赤い縦線。左右に同じ角度・同じ画風の浴場の断面図。左に「浴場」、右に「風呂屋」のラベル。問いの言葉「ヨーロッパにも銭湯？」（黄色）。時代は入れない |
| 形式 | 教える側と聞く側の2人の問答（名前は未定。台本では「教える側」「聞く側」と書く） |
| 長さ | 20〜30分 |

### 5つの部品

| 部品 | 内容 |
|---|---|
| ①当たり前 | ヨーロッパの人は風呂に入らない／銭湯は日本の文化 |
| ②裏切り | 中世ヨーロッパの都市にも、お金を払って入る公衆浴場がたくさんあった |
| ③証拠 | デューラーの木版画「男たちの浴場」と、『洛中洛外図屏風』などに描かれた京都の風呂屋 |

## 2. 台本の流れ（設計書 第7章に当てはめたもの）

| 順番 | 中身 |
|---|---|
| 1. つかみ | 聞く側「ヨーロッパの人って、昔は風呂に入らなかったんでしょ？」。教える側「実は、町に銭湯がたくさんあったんです」。答えの半分（あった）を見せ、なぜ消えたかは最後まで伏せる |
| 2. 世界の側 | 中世ヨーロッパの都市の公衆浴場。数、入り方（蒸し風呂が中心）、料金、社交の場だったこと。デューラーの版画を見せる |
| 3. その頃、日本では | 室町〜戦国の京都の風呂屋。同じく蒸し風呂が中心。風呂の起こり（寺の施浴）。屏風の場面を見せる |
| 4. 同じ問題、違う答え | 梅毒が両方に来た（ヨーロッパ1490年代、日本1512年の記録）。ヨーロッパの都市は浴場を取り締まり、浴場は減っていった。日本は、のちに湯女（1657年）や混浴（1791年）を取り締まったが、風呂屋は残った |
| 5. なぜ違ったか | 「考えられる理由」として並べる。①病気と浴場の結びつき（ヨーロッパでは1348年のペストの時から入浴が病気の危険とされた。日本ではペストは1899年まで確認されず、梅毒を湯屋と結びつけた取り締まりの記録は見つかっていない）②何を取り締まったか（日本は売春や混浴を取り締まり、風呂そのものは残した）。燃料（木材）は両方とも足りなかったので、それだけでは説明できないことも言う |
| 6. 今 | 今も日本には銭湯があり、ヨーロッパの町にはほぼない |
| 7. 持ち帰る見方 | 「日本人は風呂好きで清潔」という考えは、明治時代に西洋と比べる中で作られた（川端美季『風呂と愛国』）。「ヨーロッパは不潔」も同じく作られた当たり前。どちらが優れているかではなく、同じ問題に違う答えを出した、という話で締める |

### 言ってはいけないこと（これまでの調査で分かった落とし穴）

- 「フランクフルトの浴場が15軒から2軒に減った」（15軒は210年間の合計）。
- 「梅毒が浴場を消した」と理由を1つに決めること。
- 「中世の人はみんな毎日風呂に入っていた」（浴場は主に都市のもの）。
- 「日本の風呂屋が残ったのは〇〇だから」と言い切ること（研究者がそう言っている出典はない）。
- 「ヨーロッパ全体で同じだった」（近世イギリスについては、体を洗うことを勧める文献が多いという反論がある：Susan North『Sweet and Clean?』2020）。
