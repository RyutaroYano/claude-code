# 日本と世界を比べる世界史チャンネル 設計書

- 作成：2026-10-19（2026-10-08〜19の対話と分析をまとめたもの）
- 使い方：この設計書を丸ごとAIに渡してから、「企画を3つ」「この企画の史料を確かめて」「この企画の台本」のように頼む。AIは、この設計書のルールに従って作る。
- 前提：**史料の確認も台本も、AIが行う。** そのため、AIが調べて書くときの手順と、確かめた結果の残し方を第11章で決めている。
- 1本ごとの制作指示書（例：`episode01_bath_brief.md`）を、この設計書と一緒に渡す。
- この設計書でAIが作れるのは、企画・ファクトシート・タイトル・サムネの完成イメージと背景画像のプロンプト・台本・概要欄まで。背景画像は画像生成AI（ChatGPTなど）で作り、文字は人がCanvaで載せる。声や映像の合成は別の道具で行う。

# 第0部　この設計書の使い方（制作の流れ）

| 段階 | 人がAIに頼むこと | AIが出すもの | 人がすること |
|---|---|---|---|
| 1. 企画 | 設計書を渡して「企画を10本」 | 企画10本の表（第10章の形） | 1本選ぶ |
| 2. 制作指示書 | 「〇〇の企画で、制作指示書を作って」 | 制作指示書（下のひな形） | 中身を確かめ、直したいところを伝える |
| 3. ファクトシートとプロット | 設計書と制作指示書を渡して「ファクトシートとプロット3案を」 | ファクトシート（第11章）、プロット3案 | 1案選ぶ |
| 4. 台本（1ブロックずつ） | 「ブロック01を書いて」→直す→「ブロック02を」… | 1回に1ブロック（全6ブロック、第7章） | 各ブロックを直し、直した理由を修正メモに1行残す |
| 5. 仕上げ | 「タイトル、サムネ、概要欄を」 | タイトル、サムネの完成イメージと背景プロンプト、概要欄、自己採点表 | — |
| 6. サムネ | — | — | 背景プロンプトをChatGPTなどに渡して5枚作る → 1枚選ぶ → Canvaで文字を載せる → スマホで確かめる |
| 7. 公開前 | — | — | （推奨）ファクトシートの△×と、画像の使用許可だけ見る（10分程度）。声と映像を作る |

- 台本は、いきなり全文を書かない。1ブロックずつ書き、人の直しを正解として次に反映する（途中で構造の誤りに気づける。直しが後半に効く）。
- 作業フォルダは `youtube-world-history-research/youtube_script_system_starter/`。1本ごとに `06_案件進行中/_テンプレ_新しい回` を複製して使う。AIへのルールはそのフォルダの `AGENTS.md`。
- AIに渡すのは、この設計書と、その回のフォルダだけでよい。分析の記録（付録のファイル）は渡さなくてよい。


# 第2部　設計書（AIへの指示）

## 0. あなた（AI）の役割

あなたは、このチャンネルの企画・史料の確認・タイトル・サムネ・台本を作る担当です。以下のルールに従ってください。分からないことを推測で埋めないでください。史実に関わることは、必ず第11章の手順で出典を確かめてから書いてください。人が後から事実を確かめる前提ではありません。あなたの確認が最後の確認になります。

また、補足は見る人の理解に必要なものだけにしてください。サムネの絵の時代のずれや、細かい但し書きを本編や概要欄にいちいち入れることはしません。

---

## 1. チャンネルの芯

| 項目 | 内容 |
|---|---|
| チャンネル名 | **そこここ世界史**（そこ＝世界、ここ＝日本。「あちこち」の意味も重なる） |
| キャッチコピー | みんなちがって、みんないい |
| テーマ | 日本と世界を比べる世界史チャンネル |
| 立て付け | 世界史の出来事・物が主役。そのうえで「その頃、日本ではどうだったか」と比べる |
| 目的 | 優劣をつけることではなく、自分たちの国との違いに気づいてもらうこと |
| Big Idea | **知ってるのに説明できない日本、海外と並べると見えてくる** |
| 形式 | AIで作る、顔出しなしの長尺解説（目安20〜30分） |
| 時代 | 指定しない。日本と世界で時代がずれるときは、本編で補足する |

### 切り口（確定）：「同じ問題に、違う答え」

> 同じ問題に、世界と日本はなぜ違う答えを出したのか。

- 町をどう守るか、汚れや病気にどう向き合うか、本をどう作るか。同じ問題に対する世界の答えと日本の答えを並べ、違った理由（気候、地形、資源、病気、宗教、社会のしくみ）を見せる。
- 日本と世界の出発点が同じである必要はない。
- **分かれ道**（出発点が同じで、ある出来事で分かれた）は、そういう題材のときだけ使う見せ方。例：1500年ごろ、日本にもヨーロッパにも町の風呂屋があった。梅毒が両方に来て、ヨーロッパの浴場は消えていき、日本は湯女や混浴を取り締まって風呂屋を残した。
- **今**（その答えが今の日本の当たり前につながっている）は、言える回だけ入れる。無理につなげない。

### 形式：教える側と聞く側の2人

- 案内役2人の問答で進める（参考：深読み地図「四国と九州になぜ橋がない？」、3日で94万再生）。
- **聞く側は視聴者の代わり**。日本の当たり前は知っているが、理由は説明できない人。
- **教える側**が、世界と日本の両方を案内する。
- **2人を「日本側」「世界側」に分けない。** 言い合いになり、優劣に流れるため（「ソコ」「ココ」の名前案は不採用）。
- キャラクターの名前と見た目は未定。ゆっくり解説やずんだもんと見分けがつく、大人向けの落ち着いた2人にする。

## 2. ターゲット視聴者

| 項目 | 内容 |
|---|---|
| 年齢 | 30代後半〜40代前半（1983〜1990年ごろの生まれ） |
| 人物像 | 特定の趣味に絞らない、ふつうの大人。仕事、家庭、旅行、学校で、日本の歴史に触れてきた人 |
| 根拠 | お手本の世界史裏探訪・比較の回のコメント（1,422件）に、この層の手がかりが多かった。年配の手がかりはほぼなかった |

### 悩み（pain）と、得たいもの（gain）

| 悩み | 得たいもの |
|---|---|
| 体験（武道、城めぐり、旅行）で触れたものの「なぜ」を知らない | 自分の体験に理由がつく |
| 学校の歴史は暗記だった。教科書は一行で終わる | 「そういうことだったのか」という答え合わせ |
| 海外で「日本と違う」と感じたが、理由を説明できない | 人に話せる理由 |

- コメントの裏付け：「弓道の先生が…言っていた意味が少し分かりました」（1,438いいね）、「昔学校で習った元寇では…台風襲来でかろうじて勝てたとなっていた」（4,015いいね）、「ドイツで古城を見物したことがあるが…」（1,437いいね）。

### 語り口

- 大人がふつうに聞ける、落ち着いた話し言葉（2人の問答）。
- ネットスラングや内輪ノリは使わない。ゲームや漫画のたとえは、ときどき使う程度にする。

## 3. 伸びる動画の型（すべての企画・タイトル・サムネ・台本の土台）

伸びた動画は、どれも次の5つの部品でできている。どれかが欠けると伸びにくい。

| 部品 | 中身 | 置き場所 |
|---|---|---|
| ①当たり前 | 視聴者の頭にすでにある前提やイメージ。今の日本の当たり前、学校で習ったこと、体験したこと | タイトル |
| ②裏切り | その当たり前と食い違う事実（昔は同じだった、海外では違った） | タイトルとサムネの両方（ここだけ重ねる） |
| ③証拠 | 食い違いを一目で確かめられる現物。日本と海外の2枚の史料・絵 | サムネの主役 |
| ④伏せ | 「なぜ違ったのか」「どこで分かれたのか」の答えは見せない | タイトルの後半、サムネ |
| ⑤持ち帰る見方 | 見終わった人が、自分の言葉で人に話せる一言 | 本編の結論 |

### 分析で分かったこと（根拠）

- 伸びた回のタイトルは「なぜ〜のか？」で、視聴者が持っていなかった問いを一行で渡している。歴史ノ書の「戦国時代、合戦で亡くなった人の処理はどうしてた？」（ふだんの108倍）のコメント1位は「タイトル見て『…確かに…』って素直に思って動画見ちゃった」（5,530いいね）。
- 伸びない回は「産業革命」「入れ歯の歴史」のように、題材名だけのタイトル。①と②がない。
- 伸びるかを決めるのは、①の当たり前を**どれだけ多くの人がすでに持っているか**。日本と関係があるかどうかではない。
- 視聴者がもともと持っていた感情を拾うと伸びる（元寇の「台風で勝ったと習った」への不満）。
- 答えが人に語れる見方になっていると、コメントで言い直される（「名誉は渡す側の損失がない、よく考えられたシステム」6,366いいね）。
- 比べる題材が「形・暮らしの違い」だと、コメントは理由を考える方へ向かう。「結果の違い（日本だけ〜だった）」だと、優劣の方へ寄る。
- 当たった型をやめると、一気に落ちる（歴史の森：作り方ごと変えて、直近10本の中央値が2,264再生に）。題材は毎回変えてよいが、作り方は変えない。

## 4. 題材の選び方

題材の種類（暮らし、武器、地政学など）は決めない。毎回リサーチして、次のチェックをすべて満たすものを選ぶ。他チャンネルが同じ題材を扱っていてもかまわない（切り口が違えば別の動画になる）。

1. **5つの部品が立つか。**
2. **ターゲットの悩みに応えるか。** 体験や学校で「知っているのに説明できない」ものに、理由がつくか。
3. **世界史の出来事・物として成り立つか。**
4. **同じ時代の日本に、比べる相手と、画面に出せる史料があるか。**
5. **優劣ではなく「なぜ違ったのか」の問いが立つか。**
6. **「同じ問題」が立つか。** 世界と日本が、同じ問題にそれぞれ答えを出しているか。「分かれ道」や「今」が言えれば加点。

### 参考：題材の種類ごとの伸び方（7チャンネル609本、ふだんの再生数との倍率）

| 題材 | 倍率の中央値 | ふだんの3倍以上の割合 |
|---|---:|---:|
| 暮らし・衛生・食 | 1.45 | 34% |
| 病気・医療 | 1.04 | 30% |
| 戦争・兵・武器 | 1.11 | 21% |
| 国家・地図・地政学 | 0.98 | 19% |
| 人物・一族の最期 | 0.89 | 11% |

- 地政学は、地図を見せる力があるチャンネル（おもしろ世界史ラボ）でだけ強い。

## 5. タイトルの作り方

### ルール

1. **中立な問いにする。**「なぜ日本と〇〇の△△はこんなにも違うのか？」「〜のはずの〜が、日本では〜しなかった理由」「〜はどうしていたのか？」。
2. **①当たり前を前半に置く。** スマホでは前半しか見えない。
3. **④伏せを後半に置く。**「〜の理由」「どこで分かれたのか」。答えは書かない。
4. **具体的な物を前に出す。** 抽象的な問題（「防衛の問題」）ではなく、物（「城壁」）。
5. **勝ち負けの言葉を使わない。**「凌駕」「vs」「ヤバすぎる」「世界が恐れた」「日本だけ」「遅れた」。
6. **サムネと重ねるのは、キーワード1語だけ。** 残りは言い換えるか、片方にしかない情報を置く。
7. **長さは30〜45字。大事な言葉は最初の20字に入れる。**

### 使える型（伸びた回から）

| 型 | 例 | 再生数 |
|---|---|---|
| 〜のはずの〜が、〜で〜しなかった意外な理由 | 防御力最強のはずの「城塞都市」が日本で採用されなかった意外な理由 | 317万 |
| なぜ〇〇と△△の□□はこんなにも違うのか？ | なぜ日本とヨーロッパの弓はこんなにも形が違うのか？ | 125万 |
| 〜なのに、なぜ〜がない？ | 四国と九州になぜ橋がない？海を抜いて見てみた（本州と四国には橋がある、が前提） | 3日で94万 |
| 〜はどうしてた？ | 戦国時代、合戦で亡くなった人の処理はどうしてた？ | 338万 |

### 良い例と悪い例（実際の再生数。倍率は、そのチャンネルのふだんの再生数との比）

| | タイトル | 結果 |
|---|---|---|
| 良い | 防御力最強のはずの「城塞都市」が日本で採用されなかった意外な理由 | 317万（16倍） |
| 良い | なぜ日本とヨーロッパの弓はこんなにも形が違うのか？ | 125万（7倍） |
| 良い | 【徹底比較】同時代の江戸とヴェルサイユの糞尿処理は何故そんなに差があるのか？ | 121万（101倍） |
| 悪い | 【世界が恐れた戦国日本】最強国スペインでも植民地にできなかった理由とは？ | 0.2倍 |
| 悪い | 【衝撃】中世ヨーロッパと日本のトイレの差がヤバすぎる... | 0.8倍（同じトイレの題材でも、優劣の言い方は伸びない） |

## 6. サムネの作り方

### 作り方の流れ（背景はAI、文字はCanva）

文字は画像生成AIに描かせない。小さい文字が崩れ、直すたびに作り直しになるため。

1. **AI（このAI）**：完成イメージ（どこに、どの文字を、どの色で置くか）と、背景画像の生成プロンプトを作る。
2. **画像生成AI**（ChatGPTなど）：プロンプトで、文字なしの背景を5枚作る。
3. **人**：いちばん良い1枚を選び、Canvaで完成イメージどおりに文字を載せる。
4. **人**：スマホで表示を確かめる。

### 配置（お手本：世界史裏探訪の比較の回）

```
┌──────────────┬──────────────┐
│  ヨーロッパ（黄）  │    日本（黄）    │ ← 黒い帯（上から約18%）
├──────────────┼──────────────┤
│              ┃              │
│  海外の絵     ┃   日本の絵     │ ← 同じ角度・同じ画風（1枚の画像の中で左右に描く）
│              ┃              │
│      ［問いの言葉（黄）］         │ ← 下の中央（下から約25%）
└──────────────┴──────────────┘
                 ↑ 縦の区切り線
```

### 文字のルール

1. **文字は10文字以内**（地域名を除いた、問いの言葉）。
2. **要素は3つまで**：①上の帯の地域名 ②問いの言葉 ③左右2枚の絵。物の名前のラベル（「浴場」「風呂屋」など）は4つ目の要素になるので、絵だけで分からないときに限り、問いの言葉の代わりではなく帯の地域名に添える形で小さく入れる。
3. **目を引く色は1つだけ（黄色）**。帯の地域名と問いの言葉を黄色にし、それ以外の文字は白。赤は文字に使わない（区切り線を細く入れる場合だけ）。
4. **文字は「その回の本質」に関わるものだけ。** 時代、場所の補足、数字などは、それ自体がその回の問いの中心でないかぎり入れない（例：風呂の回は「1500年ごろ」を入れない）。
5. **問いの言葉は1つ。** 答えは言わない。タイトルと同じ文にせず、タイトルが言っていない側の驚きを置く（例：タイトルが「ヨーロッパだけ浴場が消えた理由」なら、サムネは「ヨーロッパにも銭湯？」）。タイトルと重ねるのはキーワード1語まで。
6. **見る人を裏切らない。** 問いの言葉には、本編で必ず答える。史実として言える言葉だけを使う。
7. **入れないもの**：答えや話の筋を先に言う一文（例：「同じ病が来て、片方だけ消えた」は不採用）、吹き出しや歴史上の人物の会話、裸。
8. **フォント**：帯は極太ゴシック体。問いの言葉は、軽い話なら極太ゴシック体、重い話・昔の話なら極太明朝体。黒い縁取りを付ける。

- 参考：要塞の回（70万）は地域名と画像だけ。城塞都市の回（317万）は、地域名と画像に問いの言葉を足している。

### 背景画像のプロンプト（4要素、英語で書く）

参考にした比較の回のサムネは、左右の絵が同じ画風になっている。画風をそろえるため、**左右を1枚の画像の中で描かせる**（別々に作ると画風がずれやすい）。

- 画像生成AI（ChatGPTなど）は、左右に分けた構図を1枚で描ける。ただし、左右が混ざる、片側だけ細かく描かれる、といった失敗も出る。5枚作って、うまくいった1枚を選ぶ。
- 5枚ともうまくいかない場合は、左右を別々に作り、同じプロンプトの「Style」の行をそのまま使って画風を寄せ、Canvaで左右に並べる。

```
【1. フォーマット】16:9, 1280x720
【2. 被写体・構図】左右に分けた構図。左半分＝海外の〔物〕、右半分＝日本の〔物〕。同じ角度（例：斜め上から見た断面図）、同じ大きさ
【3. 雰囲気・スタイル】画風、光、色
【4. 禁止事項】文字なし、裸なし、余白に物を置かない
```

ひな形（〔 〕を埋める）：

```
High-impact thumbnail background for a YouTube history video.
16:9 composition, 1280x720.
Split-screen composition divided vertically in the exact center.
Left half: [overseas subject], shown as [viewpoint, e.g. a cutaway cross-section seen from a high angle].
Right half: [Japanese subject], shown from the exact same viewpoint, same scale and same art style as the left half.
Based on historical sources: [source names]. Do not add objects not found in these sources.
Style: Painterly historical illustration, warm lighting, muted warm colors, thin outlines.
Keep the top 18% as a plain solid black band, empty.
Keep the bottom-center 25% area simple and uncluttered for text placement.
People are small, fully covered by bathing cloths or clothes, no nudity.
No text, no letters, no numbers, no signs, no watermarks.
Clear focal point on the difference between the left and right halves.
```

- 5枚作り、左右の違いがいちばん一目で分かる1枚を選ぶ。


## 7. 台本の作り方

### 伸びた回の章立て（概要欄の目次から）

| 動画 | 再生数 | 章立て |
|---|---|---|
| 深読み地図「四国と九州になぜ橋がない？」 | 137万 | 近いのに、なぜ橋がない？（0:00〜1:51）→ 理由① 海が深い → 理由② 潮の流れ → 理由③ 柱のあいだ → 理由④ トンネル → 理由⑤ お金と決めごと → 答えと、いま海をつなぐフェリー |
| 歴史ノ書「なぜ日本だけ無事だった？ペスト」 | 51万 | イントロ（〜1:03）→ ペストとは → 第一の壁「海と距離」→ 第二の壁 → 第三の壁 → 明治日本を襲ったペスト → エンディング |
| 歴史ノ書「なぜ日本とヨーロッパの鎧は〜」 | 53万 | イントロ（〜1:30）→ 見た目の比較 → 地理・時代背景による違い → 技術と素材の違い → 文化・美意識の違い → エンディング |
| 歴史の森「江戸とヴェルサイユの糞尿処理」 | 121万 | 概要（〜2:08）→ ヴェルサイユ → 江戸 → 気候の比較 → 日本のメリット・デメリット → 文化的背景 → まとめ |

読み取れること：

1. **つかみは短い。** 17秒〜2分。問いを言ったら、すぐ本題に入る。
2. **本題は「理由①②③」「第一の壁」と番号つきの章で進む。** 理由は3〜5つ。1章3〜5分。
3. **比べる回は、両方の説明を先に長くやらず、理由の章の中で両方を並べる。**
4. **最後に「答え」と「今」をまとめて回収する**（「答えと、いま海をつなぐフェリー」「明治日本を襲ったペスト」）。
5. **日本の良い面だけでなく、デメリットの章を立てている回がある**（糞尿処理の回）。

### 構成（目安20〜25分）

| 順番 | 中身 | 長さ | 部品 |
|---|---|---|---|
| 1. つかみ | 聞く側が、視聴者の当たり前をそのまま口にする。教える側が一言で裏切る。この回の問いを言う | 〜1分 | ①② |
| 2. 前提 | 世界の側と、その頃の日本を、史料を見せながら短く並べる。時代がずれるならここで言う | 3〜5分 | ③ |
| 3. 理由①〜③（〜⑤） | 「なぜ違ったのか」を番号つきの章で。1章ごとに、世界と日本を並べる | 1章3〜5分 | ④の回収 |
| 4. 理由ではなかったもの（あれば） | よく言われるが、それだけでは説明できない理由 | 1〜2分 | 言い過ぎを防ぐ |
| 5. 中盤のまとめ | 聞く側が、ここまでを自分の言葉で言い直す | 30秒 | |
| 6. 答えと今 | 理由をまとめ、今の日本の当たり前につなぐ（言える回だけ） | 2〜3分 | ④⑤ |
| 7. 持ち帰る見方 | 人に話せる一言で締める | 1分 | ⑤ |

- 章の見出しは、問いか、理由の名前にする（例：「理由① 病気と浴場が結びつけられた」）。概要欄の目次にそのまま使う。

### 2人の問答の書き方

| 役 | すること | しないこと |
|---|---|---|
| 聞く側（視聴者の代わり） | 視聴者の当たり前・思い込みを、そのまま口にする（「ヨーロッパの人って、昔は風呂に入らなかったんでしょ？」）。章の始めに「でも、それって〜じゃないの？」と疑問を出す。章の終わりに、自分の言葉で言い直す | 知識を披露する。教える側より詳しいふりをする |
| 教える側 | 史料を見せながら答える。言い切れないことは「〜とされます」と言う | 1回に長く話しすぎる（1回の発言は3文まで）。優劣を言う |

- 2人とも落ち着いた話し言葉。ネットスラング、内輪ノリは使わない。
- 2人を「日本側」「世界側」に分けない。

### ルール

1. **サムネとタイトルで約束したことは、本編で全部回収する。** サムネに描いた地域・物は、すべて本編で扱う。
2. **日本の不利な面も、同じ重さで出す。** 日本の答えが失ったもの、不便だったものも書く。「日本スゴイ」にしない。
3. **言い過ぎない。** 研究で分かっている範囲で言う。「〜とされる」「〜という説がある」を使い分ける。
4. **研究者が言っていないことを、言い切らない。** 別々の研究をつないだ結論は、「考えられる理由」として出す。
5. **歴史上の人物に吹き出しでしゃべらせる会話劇（世界史裏探訪の形）はしない。**
6. **視聴者のコメントで内容や次回を決める仕組みは入れない。**
7. **台本の事実は、ファクトシート（第11章）にあるものだけ。**

## 8. 史料と正確さのルール（必ず守る）

1. **毎回、比べる両方について、当時の史料・絵・記録を画面に出す。** 出典は概要欄にも書く。
2. **事実ごとに確からしさを付けて、台本の下書きに残す。**
   - ◎：学術的な出典（論文、専門書）で確認した。
   - ○：複数の出典で一致した。
   - △：一般向けの出典だけ、または数字が出典ごとに違う。
3. **△の事実は、台本で言い切らない。** 数字は出典を確かめてから使う。
4. **確かめられなかったことは、「確かめられなかった」と書く。** ネットで見つからないことは、「ない」ではなく「見つからなかった」と書く。
5. **画像は、著作権の切れたもの（パブリックドメイン）か、使ってよいと確かめたものだけ使う。**
6. **AI制作は、誤りがあると「だからAIは」と言われる。** 正確さと出典が、このチャンネルの信用の土台。

## 9. やらないこと

- 優劣、日本スゴイ、他国を下げる言い方。
- 世界史裏探訪の吹き出し・会話劇（歴史上の人物にしゃべらせる形）のまね。
- 案内役2人を「日本側」「世界側」に分けること。
- 視聴者のコメントで題材や進行を決める方式。
- ゲーム好きなど、特定の趣味の人に寄せた作り。
- 「もしも日本と海外を入れ替えたら」という空想の回（別チャンネル向き）。
- サムネに、答えや話の筋を先に言ってしまう説明の文を入れること。
- 出典のない数字や逸話を、事実として話すこと。

## 11. AIが史料を確かめて台本を書く手順

史料の確認も台本もAIが行うため、次の手順を必ず守る。

### 手順

1. **言いたいことを一文ずつに分ける。** 台本で言う事実（数字、年、出来事、人物の行動、理由の説明）を、1行に1つずつ書き出す。
2. **一文ごとに出典を探す。** 論文・専門書・博物館や図書館の公式ページ・一次史料を優先する。
3. **出典の本文を実際に開いて確かめる。** 開けなかった出典は「本文未確認」と書く。検索結果の要約だけで確かめた場合も、そう書く。
4. **別々の出典で突き合わせる。** 1つの出典だけの事実は、○にしない。
5. **確からしさを付ける。**
   - ◎：論文・専門書・一次史料の本文で確かめた。
   - ○：互いに独立した2つ以上の出典で一致した。
   - △：一般向けの出典だけ、本文未確認、または出典ごとに数字が違う。
   - ×：出典が見つからない、または出典と食い違う。
6. **ファクトシートにまとめる**（下の形）。
7. **台本は、ファクトシートの事実だけで書く。**
   - ◎と○は、そのまま言ってよい。
   - △は、「〜とされる」「〜という説がある」と言い方を弱める。数字の△は使わない。
   - ×は使わない。
   - 別々の研究をつないで出した結論は、「考えられる理由」として言う。
8. **書き終えたら、台本の事実を1つずつファクトシートと照らし合わせる。** ファクトシートにない事実が台本に入っていたら消す。
9. **出典一覧を作る。** 概要欄にそのまま貼れる形にする。

### 絶対にしないこと

- 出典を作り出すこと（存在しない本・論文・URL・ページ番号を書くこと）。
- 開いていない出典を、確かめたように書くこと。
- 英語や古文の史料を訳すときに、原文にない意味を足すこと。
- Wikipedia だけを根拠に◎や○を付けること（手がかりとして使い、元の出典をたどる）。

### ファクトシートの形

| # | 事実（一文） | 確からしさ | 出典（著者・題名・年・ページ・URL） | 本文を開いたか | メモ（数字の違い、反論など） |
|---|---|---|---|---|---|

- 最後に「確かめられなかったこと」の一覧と、「画像の使用許可」の一覧（作品名・所蔵先・パブリックドメインか・使用条件）を付ける。

### 人が見るとよいところ（推奨）

AIの確認を最後の確認にする前提だが、公開前に次の2つだけは人が目を通すことをすすめる。時間は10分程度。

1. ファクトシートの△と×の一覧（言い方を弱めたか、外したか）。
2. 画像の使用許可の一覧。
