# 自分のチャンネル用 タイトル・サムネ案（叩き台3つ・第2版）

- 前提：AIで作る非属人の長尺の世界史チャンネル。
- 作り方：`unified_formula.md` の5つの部品（①当たり前 ②裏切り ③証拠1つ ④伏せ ⑤持ち帰る見方）で作った。
- 第1版から変えたこと：
  - 日本中心の題材をやめた。
  - 裏探訪の吹き出しの会話劇は使わない。
  - チャンネルごとの型を1つずつ使うのをやめて、3案とも同じ型で作った。

---

## 案1：ピラミッドを作ったのは誰か

**タイトル**
> ピラミッドを作ったのは奴隷じゃなかった？ 4500年前の"現場監督の日誌"が明かす本当の工事現場

| 部品 | 中身 |
|---|---|
| ①当たり前 | ピラミッドは、むちで打たれた奴隷が作った（映画や昔の教科書のイメージ） |
| ②裏切り | 働いていたのは、食料（パンとビール）を支給された労働者だった |
| ③証拠 | 現場監督メレルの日誌（ワディ・エル＝ジャルフのパピルス）と、ギザで見つかった労働者の墓 |
| ④伏せ | 「奴隷じゃなかった？」と問いにして、答えは本編で |
| ⑤持ち帰る見方 | 「巨大なものを作るには、恐怖より食料と仕組みが要る」 |

**サムネ**
- 構図：左に建設中のピラミッド、右に古いパピルスの日誌（文字が見える質感）。日誌が証拠の役。
- 文字：上に黄色で「奴隷じゃなかった？」（9文字）。日誌の横に赤で「給料はパンとビール」を1か所だけ。
- 色：砂の金茶色の背景。黄色＝問い、赤＝裏切りの事実。
- フォント：問いは極太ゴシック体、日誌の文字は古文書風。

**注意**：「奴隷はまったくいなかった」とまでは言わない。強制的に集められた人がいた可能性も含めて、研究の範囲で正確に話す。

## 案2：中世ヨーロッパは本当に不潔だったのか

**タイトル**
> 「中世ヨーロッパ人は風呂に入らない」は本当か？ 街中に公衆浴場があふれた時代と、それが消えた理由

| 部品 | 中身 |
|---|---|
| ①当たり前 | 中世ヨーロッパは不潔で、人は風呂に入らなかった（ネットの定番ネタ） |
| ②裏切り | 中世の都市には公衆浴場がたくさんあり、人々は入浴を楽しんでいた |
| ③証拠 | 浴場で人々がくつろぐ様子を描いた中世の写本の挿絵 |
| ④伏せ | 「では、なぜ『不潔』のイメージが残ったのか」（浴場が消えた理由）は伏せる |
| ⑤持ち帰る見方 | 「不潔になったのは中世ではなく、その後の時代だった」 |

**サムネ**
- 構図：中世の写本風の浴場の絵を大きく置く。湯船で食事や会話を楽しむ人々。
- 文字：上に黄色で「中世人、風呂好きだった？」（12文字）。下に赤で「浴場が消えた理由」を1か所だけ。
- 色：写本の金・赤・青の古い色に、黄色と赤の文字。
- フォント：問いは極太明朝体（写本の古さに合わせる）。

**注意**：浴場が消えた理由は、病気の流行（梅毒やペスト）への恐れ、燃料の木材の値上がりなど、複数の説を出典つきで扱う。

## 案3：ナポレオンは本当に背が低かったのか

**タイトル**
> ナポレオンは本当に"チビ"だったのか？ イギリスの風刺画が作った200年続くウソ

| 部品 | 中身 |
|---|---|
| ①当たり前 | ナポレオンは背が低い（「ナポレオン・コンプレックス」という言葉まである） |
| ②裏切り | 実際は約169cmで、当時のフランス人としては平均くらい |
| ③証拠 | ナポレオンの肖像と、身長を比べる目盛り（当時の平均身長の線を引く） |
| ④伏せ | 「では、なぜチビになったのか」（単位の取り違えと、イギリスの風刺画）は伏せる |
| ⑤持ち帰る見方 | 「イメージは、敵がばらまいた絵で作られることがある」 |

**サムネ**
- 構図：中央にナポレオンの肖像。横に身長の目盛りを立て、「当時の平均」の線を引く。
- 文字：上に黄色で「本当にチビだった？」（9文字）。目盛りの上に赤で「169cm」を1か所だけ。
- 色：暗い背景に肖像。黄色＝問い、赤＝裏切りの数字。
- 表情：堂々とした肖像画を選ぶ（「チビ」のイメージとの落差を作る）。

**注意**：身長の数字は、資料（検死記録の値と、フランスの単位の換算）を示す。この話は雑学としてある程度知られているので、⑤の「敵の絵がイメージを作る」まで踏み込まないと物足りなくなる。

## 3案の比べ方

| | ①当たり前を持つ人の多さ | ②裏切りの強さ | ③証拠のわかりやすさ |
|---|---|---|---|
| 案1 ピラミッド | 多い（ほぼ全員） | 強い | 日誌は説明が要る |
| 案2 中世の風呂 | 多い（ネットでよく言われる） | 強い | 絵で一目でわかる |
| 案3 ナポレオン | 多い | 中くらい（知っている人もいる） | 目盛りで一目でわかる |
