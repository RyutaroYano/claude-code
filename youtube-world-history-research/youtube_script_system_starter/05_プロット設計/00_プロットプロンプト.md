# プロットプロンプト

Cursor にプロットを作らせるときは、まずこの考え方で動かします。

## 基本方針
- プロットは「言いたいことの順番」ではなく、
  「視聴者が納得しやすい順番」で作る
- 最初に視聴者の現実を言い当てる
- 次に誤解を壊す
- その後で新しい見方を渡す
- 最後に行動に移しやすい着地を作る

## 依頼時に必ず伝えること
- 今回の目的
- 想定視聴者
- 動画の長さの目安
- この動画で絶対に伝えたい核
- 絶対に外したくない要素
- 逆に入れたくない要素

## 3 案出しの評価観点
- どの案が一番早く自分ごと化できるか
- どの案が中盤で価値落ちしにくいか
- どの案が差別化しやすいか
- どの案が CTA まで自然につながるか
