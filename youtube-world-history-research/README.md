# そこここ世界史　作業フォルダの地図

| フォルダ | 中身 | いつ使う |
|---|---|---|
| `01_設計書/` | チャンネルのルール一式（`channel_design_spec.md`）。AIに毎回渡す | いつも |
| `02_リサーチ/` | チャンネルを作るときに調べた記録 | 根拠を見返すとき |
| 　`チャンネル分析/` | 競合チャンネルの分析、伸びる型、視聴者の分析、コンセプトを決めた7ステップ | |
| 　`初期の企画検討/` | 比べるチャンネルに決める前の企画案（風呂の初期案など） | |
| 　`コメント生データ/` | 他人のコメントの生データ。git には入れない | |
| `03_企画/` | 企画案の一覧（10本ずつ） | 次の回を選ぶとき |
| `04_台本キット/` | 台本を書くAIへのルール（`AGENTS.md`）と、視聴者理解、成功と失敗の定義、競合データ、プロットの作り方 | 台本を書くとき |
| `05_各回/` | 1回分ずつのフォルダ。制作指示書、ファクトシート、プロット、6ブロックのカット表、修正メモ | 1本作るとき |
| 　`_テンプレ_新しい回/` | 新しい回はこれを複製して「第03回_〔題材〕」にする | |
| `video/` | 動画を組み立てる仕組み（Remotion）。各回の音声・画像・動画も `video/public/episodes/〔回のID〕/` に置く | 組み立てるとき |
| `scripts/` | 分析に使ったプログラム（YouTube のデータ取得、集計） | 分析をやり直すとき |

## 1本作る流れとフォルダ

1. 企画を選ぶ → `03_企画/`
2. `05_各回/_テンプレ_新しい回` を複製して、制作指示書・ファクトシート・プロット・台本をそこに書く
3. 声・画像・動画を `video/public/episodes/〔回のID〕/` に置き、`video/` で組み立てる（使い方は `video/README.md`）
