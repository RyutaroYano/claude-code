# 案2「中世ヨーロッパの風呂」の設計書

分析シートと同じ見方（誰に・約束・欲しいもの・意図・感情・サムネ）で、案2を言葉にしたもの。型は `unified_formula.md` の5つの部品。

---

## 1. 誰に向けた動画か

- **中心**：「中世ヨーロッパ＝不潔」というネットの定番ネタを、どこかで聞いたことがある人。世界史は好きだが専門ではない人。
- **広げる先**：ゲームやアニメ、なろう系で「中世風の世界」になじみがある人。舞台の元になった本物の中世を知りたい人。

## 2. 見たら何が得られると約束しているか（サムネ＋タイトルだけで受け取る約束）

- 「自分が信じていた"中世は不潔"が、ひっくり返る」
- 「では、なぜ不潔なイメージが残ったのか」の答えがわかる

## 3. 視聴者は何が欲しいのか

- 人に話せるネタ（「中世の人って実は風呂好きだったんだよ」）。
- ゲームやアニメで見ていた世界の「本当の姿」。
- 「なぜ消えたのか」という疑問の答え。

## 4. 動画制作者（自分）の意図

- 誰もが持つ「当たり前」を入口にして、世界史を知らない人にもクリックさせる。
- チャンネルの最初の1本として、「このチャンネルは、思い込みを証拠でひっくり返す」という方針を見せる。
- 会話劇に頼らず、**証拠の絵1枚**で引きつける作り方を試す。

## 5. どんな感情を動かすか

| タイミング | 感情 |
|---|---|
| サムネを見た瞬間 | 「え、そうなの？」という驚き（信じていたことと違う） |
| タイトルを読んだ後 | 「じゃあなんで消えたの？」という気がかり |
| 本編の途中 | 「人間って昔から同じだな」という親しみ（湯船で食事やおしゃべり） |
| 見終わった後 | 「人に話したい」という気持ち |

---

## 6. タイトルの構成

> 「中世ヨーロッパ人は風呂に入らない」は本当か？ 街中に公衆浴場があふれた時代と、それが消えた理由

| 部分 | 部品 | 役割 |
|---|---|---|
| 「中世ヨーロッパ人は風呂に入らない」 | ①当たり前 | かぎかっこで、視聴者の頭にある言葉をそのまま引用する。自分の思い込みだと気づかせる。 |
| は本当か？ | ②裏切りの予告 | 疑いを向けるだけで、答えはまだ言わない。 |
| 街中に公衆浴場があふれた時代 | ②裏切り | 裏切りの中身をここで見せる。サムネと重ねる部分。 |
| それが消えた理由 | ④伏せ | 答えを伏せて、再生の動機にする。 |

- 文字数：約45字。スマホでは前半しか見えないことが多いので、一番大事な①を先頭に置いている。

## 7. サムネの構成

| 項目 | 中身 |
|---|---|
| 構図 | 中世の写本に描かれた浴場の絵を、画面の左6割に大きく置く。木の湯船に男女が入り、板を渡して食事や会話をしている場面。これが③の証拠。右上に問い、右下に伏せの文字。 |
| 文字数 | 上：「中世人、風呂好きだった？」（12字）。下：「浴場が消えた理由」（8字）。合わせて20字で、ここまでに収める。 |
| 色 | 背景は写本の古い金・赤・青のまま。問いは黄色、伏せは赤。文字には黒いふちをつけて、絵の上でも読めるようにする。 |
| 人物の表情 | 絵の中の人々が**笑って楽しんでいる**こと自体が裏切り。「不潔で暗い中世」のイメージとの落差を、表情で見せる。顔が見えるように、絵の中の人物を切り抜いて大きくする。 |
| フォント | 問いは極太の明朝体（写本の古さに合わせる）。伏せの文字は太いゴシック体で、目に止まるようにする。 |

## 8. 本編で回収すること（台本の骨組みの下書き）

1. ①当たり前：「中世は不潔」というイメージを紹介する。
2. ②裏切り：都市には公衆浴場があり、人々が楽しんでいたことを、写本の絵と記録で見せる。
3. ④伏せの回収：浴場が消えた理由。病気の流行（ペスト、梅毒）への恐れ、燃料の木材の値上がり、風紀の取り締まりなど、複数の説を出典つきで扱う。
4. ⑤持ち帰る見方：「不潔になったのは中世ではなく、その後の時代だった」。

## 9. 作る前に確かめること

- **絵の出典**：使う写本の絵の所蔵先と、使ってよいか（パブリックドメインか）を確認する。候補は、15世紀のヴァレリウス・マクシムスの写本にある浴場の絵（ベルリン国立図書館所蔵とされる）。
- **数字**：「パリに浴場が何軒あった」などの数字は、出典を確かめてから使う。
- **言い過ぎない**：「中世の人はみんな毎日風呂に入っていた」とは言わない。浴場があったのは主に都市で、農村の暮らしは別だと分けて話す。
- **似た動画**：英語圏では同じ切り口の動画がすでに多い。日本語でどれだけあるかを、作る前に検索しておく。
