# Gemini と ChatGPT に渡す依頼文（大火のタイトルとサムネ）

同じ文を、Gemini と ChatGPT の両方に貼る。新しいチャットで始める。

---

## 依頼1：タイトル（文章で答えてもらう）

```
あなたは、YouTubeの歴史チャンネルのタイトルを考える担当です。次の情報をもとに、タイトルを5案出してください。

# チャンネル
- 名前：そこここ世界史
- テーマ：世界史の出来事を、同じころの日本と比べる。優劣ではなく「同じ問題に、違う答え」を見せる。
- 視聴者：30代後半〜40代前半のふつうの大人。「知っているのに説明できない日本のこと」に理由がつくのが好き。
- 形式：ナレーター1人＋AIで作った再現映像。20分前後。

# この回の中身（確かめた事実だけ）
- 1657年（明暦3年）、木造の大都市・江戸が大火で燃えた（明暦の大火）。
- その9年後の1666年、同じく木造だったロンドンが大火で燃えた。家の上の階が通りに張り出した木の町だった。
- ロンドンは1580年から「煉瓦で建てよ」という命令を何度も出していたが、守られていなかった。大火のあと1667年、法律で建物を煉瓦か石に限った。費用は石炭の税でまかなった。のちに火災保険も生まれた。
- 江戸は大火の直後、燃えないはずの瓦屋根を禁じた（落ちてきた瓦でけがや下敷きになる人が多かったため、とされる）。かわりに、空き地や広い道で燃え広がりを止め、家を壊して火を止め、財産は土蔵で守り、すぐ建て直した。
- 江戸で瓦や土蔵造りを許し、勧めたのは60年あまり後の1720年。強制はしなかった。
- 明治になって、日本は銀座を煉瓦の町にしたが、家賃の高さや湿気で空き家が増え、広がらなかった。
- 結論：ロンドンは「燃えない家を作る」、江戸は「燃えても止め、すぐ建て直す」。日本の家が木造なのは、地震だけでは説明できない。

# 視聴者の頭にある「当たり前」
- 日本の家は木造（地震に強いから）。ヨーロッパの町は昔から石と煉瓦。

# タイトルのルール
1. 中立な問いにする。答えは書かない（「なぜ」「理由」で終えるのはよい）。
2. 視聴者の当たり前を前半に置き、それを裏切る事実を入れる。
3. 30〜45字。大事な言葉は最初の20字に入れる。
4. 具体的な物を前に出す（「防災の違い」ではなく「瓦屋根」「煉瓦」など）。
5. 勝ち負けの言葉は使わない：凌駕、vs、ヤバすぎる、世界が恐れた、日本だけ、遅れた、最強、衝撃。
6. 死者の数を入れない。災害を面白がる言い方をしない。
7. 上の「確かめた事実」にないことは書かない。

# 参考：伸びたタイトルの型
- 防御力最強のはずの「城塞都市」が日本で採用されなかった意外な理由（317万回）
- なぜ日本とヨーロッパの弓はこんなにも形が違うのか？（125万回）
- 戦国時代、合戦で亡くなった人の処理はどうしてた？（338万回）

# サムネに載せる言葉（決まっている）
- 上の帯：「ロンドン」「江戸」
- 下の問いの言葉：「同じ大火なのに？」
- タイトルとサムネで重ねる言葉は1語だけにする。

# 出してほしいもの
5案を表にしてください。列は「タイトル」「字数」「視聴者の当たり前にあたる部分」「裏切りにあたる部分」「伏せている答え」「ねらい（一言）」。最後に、いちばんのおすすめ1案と、その理由を書いてください。
```

## 依頼3（おまけ）：文字まで入れたサムネ

比べるため。ChatGPT は画像の中の文字が得意とされる。日本語の文字が崩れないか見る。

```
依頼2と同じ背景で、次の文字を画像の中に入れたサムネイルを作ってください。16:9（1280x720）。

- 上の黒い帯の左半分の中央に「ロンドン」、右半分の中央に「江戸」。黄色、極太のゴシック体、帯の高さの70%くらいの大きさ。
- 下の中央に「同じ大火なのに？」。黄色で黒い縁取り、極太の明朝体、横幅の80%に収まる大きさ。
- ほかの文字は入れない。目立つ色は黄色だけにする。
```
