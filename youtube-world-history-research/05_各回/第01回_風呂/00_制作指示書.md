- 作成：2026-10-19／第2版：2026-10-23（ナレーター1人＋再現VTRの形式に合わせ、ファクトシートで分かった誤りを直した）
- 使い方：設計書（`01_設計書/channel_design_spec.md`）と一緒にAIへ渡す。事実は `ファクトシート.md` にあるものだけを使う。

## 1. 決まっていること

| 項目 | 内容 |
|---|---|
| 同じ問題 | 汚れと病気に、町でどう向き合うか |
| 世界の答え | ヨーロッパの町には公衆浴場があったが、15世紀の終わりごろから減っていった |
| 日本の答え | 日本にも町の風呂屋があり、湯女や混浴を取り締まりながらも、風呂屋は残った |
| タイトル | 同じ「町の風呂屋」があったのに。ヨーロッパだけ浴場が消えた意外な理由 |
| サムネの問いの言葉 | ヨーロッパにも銭湯？ |
| 形式 | ナレーター1人（名前なし、落ち着いたドキュメンタリーの語り）＋AI再現VTR。VTRの中で登場人物が短く話す |
| 長さ | 20〜25分が目安。今の台本は約10〜11分（下の「6. 長さについて」） |

## 2. 5つの部品

| 部品 | 中身 |
|---|---|
| ①当たり前 | 昔のヨーロッパの人は風呂に入らなかった／銭湯は日本の文化 |
| ②裏切り | 1500年ごろのヨーロッパの町にも、お金を払って入る浴場があった |
| ③証拠 | デューラーの木版画「男たちの浴場」（パブリックドメイン）と、江戸の湯屋の絵（式亭三馬『浮世風呂』の挿絵など。使用条件は未確認） |
| ④伏せ | なぜヨーロッパの浴場だけが消えたのか |
| ⑤持ち帰る見方 | 「ヨーロッパは風呂に入らない」も「日本人は昔から風呂好き」も、比べる中でできた当たり前だった |

## 4. 言ってはいけないこと（ファクトシートで分かったこと）

- 「1292年のパリに浴場が26軒」→ 26は浴場で働く**人の数**。台本では数字を使わない。
- 「1480年のバンベルクで1ヘラー」→ 出典を確かめられなかった。「料金の決まりがあった」とだけ言う。
- 「フランクフルトの浴場が15軒から2軒に」→ 15軒は210年間の合計で、出典も△。数字は使わない。
- 「『洛中洛外図屏風』に風呂屋が描かれている」→ 確かめられなかった（×）。使わない。
- 「一条の風呂」「五条堀川風呂」→ 出典を確かめられなかった。使わない。
- 「梅毒が浴場を消した」と理由を1つに決めること。
- 「日本の風呂屋が残ったのは〇〇だから」と言い切ること。別々の研究をつないだ「考えられる理由」として言う。
- 「梅毒で日本の風呂屋が取り締まられなかった」→ 「記録は見つからなかった」まで。
- 「ヨーロッパ全体で同じだった」（近世イギリスには反論がある）。
- 湯女について、ファクトシートにない仕事の中身（客と何をしたか）を言うこと。

## 5. 画面のルール

- ヨーロッパの浴場の中は、デューラー「男たちの浴場」を元にする。
- 室町時代の京都の風呂屋は、元にできる絵を確かめられていない。遠景、のれん、湯気だけで見せ、中の細部は描かない。
- 江戸の湯屋は、『浮世風呂』の挿絵などを元にする（使用条件を確かめてから画面に出す）。
- 裸の人物は小さく、湯気や布で隠す。サムネも同じ。
- 湯女の場面は、遠景と後ろ姿だけにする。
- 画面の細部（服装、建物、道具）のファクトシートは、まだ作っていない。画像を作る前に作る（設計書 第8章ルール8）。

## 6. 長さについて

ファクトシートにある28の事実だけで書くと、ナレーションは約3,100字（句読点を除く）、**約10〜11分**になる（1分300字として）。20〜25分にするには、事実を足す必要がある。足せる候補は次のとおり。

| 足せる中身 | 必要な調べ |
|---|---|
| ヨーロッパの浴場の中の様子（入り方、ひげそりや瀉血もしたこと） | Wurtzel 2023、Martin 1906 の本文 |
| 室町〜江戸の風呂屋の中の様子（戸棚風呂、ざくろ口） | Butler 2005 の本文、『守貞謾稿』 |
| 江戸の湯屋の暮らし（『浮世風呂』に描かれた会話） | 『浮世風呂』の本文（国立国会図書館デジタルコレクション） |
